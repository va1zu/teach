───────────────────────────────────────────────────────────────
ШАГ 1. СОЗДАТЬ FIREBASE (5–10 минут, один раз)
───────────────────────────────────────────────────────────────
  1) Откройте https://console.firebase.google.com
  2) «Создать проект» → любое название → далее → создать.
  3) Слева: Build → Realtime Database → «Создать базу».
  4) Регион — ближайший (europe-west1 и т.п.).
  5) Режим: сначала «тестовый» (можно), потом замените правила (шаг 2).

  6) Нажмите шестерёнку → «Параметры проекта» → «Ваши приложения» → Web (</>).
  7) Зарегистрируйте приложение → скопируйте объект firebaseConfig.

  8) Откройте config.js на компьютере и вставьте значения:

     firebase: {
         apiKey: "...",
         authDomain: "...",
         databaseURL: "https://ВАШ-ПРОЕКТ-default-rtdb.firebaseio.com",
         projectId: "...",
         storageBucket: "...",
         messagingSenderId: "...",
         appId: "..."
     }

  9) Задайте adminPassword — свой пароль для входа в админку.
