Онлайн-база Firebase

Все темы, вопросы и настройки автоматически сохраняются в Firebase Realtime Database. Ученики на GitHub Pages сразу видят изменения — как в Google-таблице, без ручной загрузки файлов.

  1. Создайте проект на console.firebase.google.com
  2. Включите Realtime Database → скопируйте блок настроек в config.js → firebase
  3. Вставьте правила из firebase-rules.json → залейте сайт на GitHub

Подробно по шагам: ИНСТРУКЦИЯ.txt. После настройки каждое сохранение в админке уходит в Firebase автоматически.
